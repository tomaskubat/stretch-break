# StretchBreak

StretchBreak reminds people to take movement breaks and preserves their exercise results locally. A release distributes the application and matching source without replacing that local data.

## Language

**Release assets**:
The portable application archive, matching source archive, application-only update archive, update feed and checksum manifest distributed together for a StretchBreak version.

**Original release assets**:
The release assets produced for a release before publication. They are the reference for proving that published copies are unchanged.

**Published release assets**:
The copies distributed through GitHub Releases, including the update feed obtained from the address used by installed applications.

**Release verification**:
Checking release assets against distribution requirements and proving that published release assets match the original release assets.
